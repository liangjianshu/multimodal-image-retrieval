# 历史实验与整理版验证

## 历史结果

作者原实验/简历记录：文搜图 F1 85%、图搜图 F1 81%；相对微调前版本分别提升 6、7 个百分点。作者确认 MLP＋LLM 的效果优于 MLP＋Vision。

这些是**作者报告的历史结果**。当前缺少完整的原始逐查询预测、固定划分和所有模块对照运行配置，不能从本仓库直接重新计算并认证这些数值。不要把它们写成官方数据集榜单成绩、当前整理版实测成绩或任意数据上的预期收益。

## 从保存产物确认的部分

找到的 `output_lora_llm` 配置对应 Qwen2.5-VL-7B-Instruct、rank 64、alpha 128；训练记录为实际 epoch 0.5、batch size 1、250 steps。另有一组 rank 16 / alpha 32 的适配器。

所检查适配器包含语言注意力的 LoRA 参数，没有发现单独保存的 merger 参数。这只能确认现存适配器的内容，不能证明 merger 当时从未更新，也不足以将两组适配器直接认定为 MLP＋LLM / MLP＋Vision 对照。用户记忆中的 rank 8 尚未由这些产物确认。

## 整理版的变化

1. 统一 CLI、相对图片路径与配置，补齐自有数据接入流程。
2. 修正难负例构造：保留真实标签，以正确否定问答呈现易混淆类别。
3. 按图片内容先划分，再扩展问答，检测训练/验证重复。
4. 区分人工真值与模型生成的检索元数据。
5. 通过 PEFT `modules_to_save` 保存连接层参数；视觉全参数模式保存完整模型。
6. 两阶段排序仍沿用类别→描述的思路；改为确定性返回、标准余弦相似度，并修正负相似度情况下的相对阈值。
7. 提供固定查询相关性标签的评测入口，避免运行时从测试标签挑选最佳阈值。

因此，整理版需要重新建立基线，不能将历史 6/7 个百分点直接附在新版本的验证结果上。

## 本次验证范围

验证数据导入与校验、训练集划分、难例答案、索引读写、两阶段排序、参考图排除和评测指标。可选模型测试使用随机初始化的微型 Qwen，验证三种参数范围、一次多模态训练更新和连接层适配器保存/恢复。

无模型 demo 的满分是预设向量下的程序正确性检查，**不是检索模型准确率**。本次没有启动服务器上的完整 7B 重训，也没有复跑 COCO/ImageNet 全量历史评测。
