# Qwen 格式归一化与类别筛选对照

2026-11-05。在查看原始固定测试结果后补充的归因诊断；**不是新的盲测，也不覆盖原始成绩**。复用已保存的模型原始输出与向量，未重新生成、更新权重或选择检查点。每种对照各自在验证集重新选择阈值，然后应用于同一测试集。

## 基座是否已经按相同规范评测？

是。`evaluate_study.py` 对基座、旧 LoRA 和新 LoRA 调用同一个 `run_qwen_trial.predict`，使用相同的图像处理配置、类别别名、最多 48 个生成 token、贪心解码（`do_sample=False`）以及提示词：

> 请识别图片中主要物体的类别。只返回一个 JSON 数组，包含最具体的中文类别名称，不要输出其他内容。

原始解析器只接受非空字符串数组。例如 `["杯子"]` 合格，`[{"类别":"杯子"}]` 虽包含正确类别，但格式不合格。这类失败会造成类别筛选漏召回，图搜图还会受到查询侧类别失败的影响。

新模型的 SFT 直接学习了该任务与输出格式。因此，同一协议能验证系统可用性，但**整体增益不能全部归因于视觉识别能力**。重复运行完全相同的推理，不会解决这个归因问题。

## 统一格式归一化

对所有模型采用相同规则：已通过原解析器的结果保持不变；其他结果尝试解析 JSON，递归收集数组／对象中的字符串值，再通过原有类别别名表映射。该过程不读取真值、不用额外模型，不从任意自由文本或否定句中猜类别；仍无法解析的输出保留为空。

在完整 2,000 张图库上，以下是五个重点类别的平均检索 F1。每类文搜图 3 条固定查询、图搜图 40 张查询图；候选图库始终含全部 15 类。完整报告另含所有类别结果。

| 对照 | 基座文搜图 | 新微调文搜图 | 差值（百分点） | 基座图搜图 | 新微调图搜图 | 差值（百分点） |
|---|---:|---:|---:|---:|---:|---:|
| 原始严格格式协议 | 60.62% | 86.76% | +26.14 | 35.64% | 81.86% | +46.22 |
| 统一 JSON 结构归一化 | 76.07% | 86.76% | **+10.69** | 63.90% | 81.86% | **+17.96** |
| 共用基座归一化类别，只更换描述向量 | 76.07% | 78.55% | +2.48 | 63.90% | 63.91% | +0.01 |
| 完全不做类别筛选，仅描述排序 | 56.40% | 61.65% | +5.25 | 36.26% | 40.81% | +4.54 |

差值按未四舍五入的原始数据计算。统一归一化后，类别预测本身的重点类别宏 F1 为基座 **78.60%**、新微调 **87.38%**；它与表中的最终检索 F1 是不同指标。旧 LoRA 的归一化检索 F1 为 **65.46%／46.40%**，仍未超过基座。

## 结果如何解释

1. 严格格式协议确实放大了基座与新微调链路的差距。基座格式归一化后，检索 F1 明显恢复。
2. 同样归一化后，新微调仍有类别检索收益；格式恢复不能解释全部差距。
3. 共用相同类别筛选结果后，描述替换带来的差异较小，尤其图搜图几乎不变。因此，该协议下主要收益集中在类别筛选阶段，不应表述为细粒度描述能力大幅增强。
4. 这些对照涉及阈值重新校准与组件交互，不能把不同实验的差值直接相加，分摊成“格式贡献百分之几、视觉贡献百分之几”。

另提供真值类别筛选（oracle）作为诊断：它直接使用图库与查询的真实类别，**不可部署，也不能作为模型成绩**。在类别相关性任务上，oracle 过滤后候选均为正例，三种描述模型 mAP 都为 1，这是任务与真值过滤的结果，不证明描述质量完美。

## 训练收益与简历口径

- 简历使用新 Qwen 最终检索 F1 **86.76%／81.86%** 和新 Embedding **88.84%／83.40%**，注明 2,000 张图库、五个主要类别及验证集阈值。
- 如介绍 Qwen 微调增益，优先同时说明归一化对照 **+10.69／+17.96 个百分点**，以及它仍是类别检索链路收益。
- 保留意图识别前期实测的 **95%／91%**；本轮固定类别查询没有复测自然语言意图。
- 历史检索 F1 85%／81% 与本轮的提示词、阈值、查询与筛选设置不同，不能跨协议计算提升。

## 限制与复现

这是查看测试结果后的诊断，不据此改动冻结选型或原始测试表。格式归一化规则固定且对所有模型相同，但仍属于事后分析。新模型已经针对类别任务及格式学习，当前对照不能完全分离指令适配与纯视觉表征学习。未新增限定 15 类提示词、约束解码推理、跨域或细粒度属性评测，也没有多随机种子显著性检验。

保留完整 study 产物后运行：

```bash
PYTHONPATH=. OPENBLAS_NUM_THREADS=4 OMP_NUM_THREADS=4 \
python examples/training/diagnose_qwen_controls.py \
  --study-root /path/to/retrieval-study \
  --output /path/to/diagnostics/qwen-controls
```

脚本验证各模型的提示词、别名、查询向量和样本顺序相同；先重算严格协议，断言 F1 与 mAP 和正式结果一致（误差小于 1e-9），再输出补充对照。输入清单、类别原始输出、向量与正式结果的 SHA-256 随输出保存。
